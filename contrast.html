The same three sentences, the same five editors, the same disagreements — told twice. First the way an ordinary shared document handles them, then the way Writ does.

A regular collaborative editor

One copy of the document. Everyone types into it at once, and an edit that arrives while someone else is mid-word simply lands on top.

0.0s

Nobody agreed to any of this. Fourteen changes, none reviewed, and the sentences no longer parse. The disagreement is invisible in the text — you would have to read the history to learn that two people were reverting each other about human nature.

02 · the alternative

Writ

The same sentences and the same people. Each edit is a proposal in the margin, and a change of meaning opens a thread the editors have to talk through before the document moves.
